# OASIS

오아시스(Oasis)를 주제로 제작한 팬 페이지 및 앨범 스토어 웹 프로젝트입니다.

## 프로젝트 소개

Oasis의 음악, 이야기, 멤버, 라이브 정보를 한곳에서 확인하고
앨범 에디션을 선택하거나 저장 및 장바구니 기능을 체험할 수 있도록 제작했습니다.

## 주요 페이지

- HOME — 메인 콘텐츠 및 새로운 소식
- STORY — Oasis의 역사와 주요 이야기
- MEMBERS — 밴드 멤버 소개
- MUSIC — 주요 앨범과 대표곡
- LIVE — 투어 일정 및 라이브 뉴스
- EDITION — 앨범 에디션
- CUSTOMIZE — 앨범 옵션 선택
- SAVED — 저장한 상품
- CART — 장바구니

## 주요 기능

- React Router를 이용한 페이지 이동
- 모바일 / 데스크톱 반응형 디자인
- 공통 Header / Drawer / Bottom Navigation
- STORY 및 MEMBERS 이미지 슬라이드
- 멤버 프로필 팝업
- 라이브 일정 및 예매 안내
- 앨범 및 대표곡 콘텐츠
- 상품 저장 및 장바구니
- 앨범 옵션 커스터마이징
- 데모 결제 안내
